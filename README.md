# hetaro-media

ヘタ郎（@hetarou.golf2026 / X @Hetarougolf）の投稿画像の置き場所です。**公開リポジトリ**です。

- 投稿画像だけを `ig/` に置きます（それ以外のファイル・秘密の値は置かない）
- GitHub Pages で `https://empowerartlab-art.github.io/hetaro-media/ig/<ファイル名>` として公開され、
  Threads / Instagram / X の自動投稿（非公開リポジトリ `threads-hetaro`）がここから画像を読みます
- ファイル名：`YYYY-MM-DD-ig-1.jpg`（Instagram、カルーセルは -2〜）、`YYYY-MM-DD-threads.jpg`、`YYYY-MM-DD-x.jpg`
- 投稿済みの画像は消さないこと（消すと投稿前のチェックで止まります）
